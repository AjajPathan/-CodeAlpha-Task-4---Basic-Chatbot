
# CodeAlpha Basic Chatbot

A simple rule-based chatbot built with Python as part of the **CodeAlpha Task 4 – Basic Chatbot** project.

# 📌 Project Description

This project demonstrates how to create a basic chatbot using Python's `input()`, conditional statements, loops, and string handling.

The chatbot can recognize simple user messages and respond accordingly.

# ✨ Features

- Greets the user
- Responds to `hello` and `hi`
- Responds to `how are you`
- Provides its name
- Explains what it can do
- Exits when the user types `bye`
- Converts user input to lowercase and removes extra spaces

# 🛠️ Technologies Used

- Python 3
- VS Code
